~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ hardware territory ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
    queues tagged TC3/VC3; requests segmented per limits.boundary
    (256B) and limits.update_granule (64B); completion counting and
    data-before-flag release happen in the requester engine

Enforcement points:

  [1] capabilities: requester DevCap3.REQ, provider UIO_COMPLETER.
  [2] range_validate(): cxl resolves the subrange to its interleave
      target set and granularity.
  [3] per-target walk up to the lowest common ancestor (LCA): flit
      mode per link, SVC routing per hop, ACS-free path (BAR) or
      ATS-capable requester (HDM).
  [4] commit, leaf -> requester, unwinding in reverse on any failure:
        a. target endpoint VCs
        b. UIO-to-HDM DVSEC gate per DSP
        c. SVC VC3 per hop
        d. requester's own VC
        e. DevCtl3.REQ_EN
  [5] limits from the path minimum (MPS, update granule).
